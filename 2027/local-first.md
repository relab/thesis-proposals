## Background and Motivation

Local first web apps are which maintain the primary data copy on the users local machine, while using cloud resources only for update and synchronization.
Local first applications prioritize user access and updates over synchronization, allowing users to use their application, also without a network connection. 
The paradigm aims for applications that remain usable, even when application providers go out of business.

The goal for this thesis is to assess the maturity of frameworks for local-first applications.

## Project Description

The goal for this thesis is to implement a local-first web-app like a workout logger or dietary logger.
As part of this process you should survey and assess existing frameworks for building local-first applications like NextGraph, Jazz, Willow, At protocol, or Automerge.
The goal is to establish the maturity of existing tools, and identify any hurdles in development and deployment of local-first applications.
